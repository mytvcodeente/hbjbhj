# DesmosCalc - Online Graphing Calculator

Welcome to **DesmosCalc**, a free and interactive online graphing calculator built using [Desmos](https://www.desmos.com/calculator). This website allows users to plot equations, visualize functions, and explore mathematical concepts easily and intuitively.  

## 🔗 Live Demo
Check out the live site here: [https://desmoscalc.github.io/](https://desmoscalc.github.io/)

## 🖥 Features
- Fully embedded Desmos Graphing Calculator
- Plot linear, quadratic, trigonometric, and other functions
- Dynamic sliders for interactive learning
- Mobile-friendly and responsive design
- Free and easy-to-use without any downloads or installations

## 📚 How to Use
1. Open the live site or run locally by opening `index.html`.
2. Enter equations in the input field.
3. Watch your graph appear instantly.
4. Zoom, pan, and adjust sliders to explore graphs interactively.

## 💻 Technology Stack
- HTML5 & CSS3
- Responsive design for mobile and desktop
- Embedded Desmos Calculator via iframe
- Hosted on GitHub Pages
